# P5R Tae Takemi Theme v1.3.1

## 中文

已验证兼容 Codex Dream Skin **v1.5.20 / v1.5.21**（Windows、macOS）。

- Windows 与 macOS 运行时安装器改为检查实际结构和语法，不再写死特定上游版本。未验证的未来版本不保证兼容。
- 运行时备份按实际上游版本分别保存，防止交叉覆盖。
- 优化 Windows Node.js 警告对校验流程的影响。
- 保持 Persona 5 Royal / 武见妙原有视觉、布局、静态低负载特性以及中英文界面文案不变。
- 安装包包含 Windows 与 macOS 安装入口，macOS 脚本保留可执行权限。

**安装要求**：先安装 Codex Dream Skin。支持 Windows、macOS。若检测到运行时结构不兼容，安装程序会安全停止。

## English

Verified against Codex Dream Skin **v1.5.20 and v1.5.21** on Windows and macOS.

- Runtime patches validate required structure and syntax instead of enforcing a fixed upstream version allowlist. Future versions are not automatically guaranteed.
- Per-version backups to prevent restoring incompatible runtime files.
- Improved Windows validation tolerance for harmless Node.js warnings.
- No changes to the P5R / Tae Takemi visuals, layout, bilingual UI text, or low-overhead static design.
- Includes Windows and macOS installers; the macOS launcher retains executable permissions in the ZIP.

**Unofficial fan-made theme.**
